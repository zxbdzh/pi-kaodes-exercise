# Pi 考得尚刷题插件 (pi-kaodes-exercise)

在 Pi 应用程序终端内直接访问并练习 kaodes.com 题库，集成了 **交互式 TUI 答题卡**、**全模块题库接入**、**Token 状态管理与交互式补填**，以及带有 **[T] 不剧透思路点拨** 与 **[F] 反问闪卡** 机制的 AI 伴学导师。

---

## 🌟 核心特性

1. **全模块题库覆盖**：支持章节练习（层级树状展开、断点记忆）、每日一练、错题本攻坚、模拟考试与答题闯关。
2. **终端交互式 TUI 刷题卡**：
   - 键盘快速作答（单选、多选、主观题要点自检）。
   - 实时答题卡矩阵状态展示（未做 `○`、已做 `●`、正确 `✔`、错误 `✘`）。
   - 进度保存与云端同步（随时按 `S` 暂存，做完按 `Q` 交卷结算）。
3. **安全凭证管理**：
   - 支持环境变量 `KAODES_TOKEN` 或本地持久化配置文件 `~/.pi/kaodes-token.json`。
   - 自动检测 JWT 状态与过期时间；失效时友好提醒并呼出输入框，用户直接粘贴 Token 即可热更新。
4. **深度 AI 伴学导师**：
   - **[T] 键思路点拨**：防剧透提示词引导，分析错因与概念界限，绝不直接泄题。
   - **[F] 键反问闪卡**：苏格拉底式变式反问互动，考察知识点内涵掌握情况。

## 🚀 快速安装与配置

### 1. 安装与构建
```bash
cd F:/github/pi-kaodes-exercise
npm install
npm run build
```

### 2. 在 Pi 中加载扩展

先构建，再直接加载编译后的扩展入口：
```bash
cd F:/github/pi-kaodes-exercise
npm run build
pi --extension F:/github/pi-kaodes-exercise/dist/index.js
```

也可以在 Pi 启动后通过本地扩展安装机制加载项目目录；为了避免加载到旧的 `dist`，每次改源码后先执行 `npm run build`。

### 3. 配置与更新 Token

进入 Pi 后输入：
```text
/kaodes login
```

在 Pi 的输入框中粘贴浏览器开发者工具里捕获的 `token` Header，或者粘贴完整 Cookie。插件会提取并保存到：
```text
~/.pi/kaodes-token.json
```

也可以在启动 Pi 前设置：
```powershell
$env:KAODES_TOKEN = "你的JWT"
```

Kaodes 接口实际使用的是原始 `token` Header 和 `platform: Pc`，不是 `Authorization: Bearer`。

| 命令 | 说明 |
| :--- | :--- |
| `/kaodes` 或 `/kaodes chapter` | 启动章节练习（默认加载已选科目的最新章节题库） |
| `/kaodes daily` | 启动每日一练（精选 10 题速练） |
| `/kaodes wrong` | 启动错题本精练攻坚 |
| `/kaodes exam` | 启动全真模拟考试 |
| `/kaodes challenge` | 启动答题闯关挑战 |
| `/kaodes login` | 手动输入并更新登录凭证 Token |

## ⌨️ 选择列表快捷键（科目 / 课程 / 章节）

章节等长列表使用内置分页选择器，每页 15 条，标题旁显示 `第 x/y 页`：

* **`↑` / `↓`（或 `K` / `J`）**：移动光标，跨页连续。
* **`←` / `→`（或 `H` / `L`、`PgUp` / `PgDn`）**：翻到上一页 / 下一页。
* **`Enter`**：确认选择当前项。
* **`⌫ Backspace`**：返回上一级选择（科目页再按则退出流程）。
* **`Esc` / `Ctrl+C`**：取消并退出整个流程。

答题页按 `Esc` 会弹出组件内退出对话框（保存断点并退出 / 不保存退出 / 继续答题），同样用 `↑↓` + `Enter` 操作，再按 `Esc` 继续答题。

## ⌨️ 做题看板快捷键说明

进入做题界面后，支持直接键盘操作：

* **`A` - `E`**：选择选项（多选题可连续按键切换选项）。
* **`F`**：触发 **AI 伴学反问闪卡模式**；Pi 内交互中优先作为伴学快捷键。
* **`V` / `Enter`**：展开 / 折叠查看官方详细答案与解析。
* **`N` / `→`**：切换至下一题。
* **`P` / `←`**：切换至上一题。
* **`S`**：暂存当前答题进度至官方服务器与本地断点缓存。
* **`Q`**：提交答卷，完成练习结算，输出正确率成绩单并退出。
* **`T`**：呼出 **AI 伴学导师思路点拨**（启发式提示，防剧透）。
* **`Ctrl + C`**：随时退出并保持本地断点进度。
